📖 System Purpose & Workflows

Semiconductor Sanity Check & Shift Analyzer provides automated verification of ATE (Automated Test Equipment) test program revisions, parameter shifts, and bin yield migrations across wafer sort (CP1/CP2/CP3) and final test (FT).

Key Workflows & Features:

  • Drag & Drop Upload: Drop any `.csv` output from your test environment into the top banner. The system automatically inspects headers and updates the dashboard.
  • 🔁 Repeatability & Gauge R&R: Multi-ECID measurement repeatability, per-die CV% dispersion, intrinsic process capability $C_p$, distribution morphology (`Dist`, `Dist_Repeat`), and temporal drift analysis (`Trend`).
  • Number Traceability (Click-to-Trace): Click any KPI card, chart bar, or table cell to open the Traceability Inspector showing the exact mathematical formula and raw CSV rows.
  • Chart Fullscreen Maximize (⛶ 一鍵放大 / ESC 還原): Click the `⛶` button on any chart header or double-click any chart to open high-resolution fullscreen modal view. Press ESC or click ✕ to restore.
  • Adjustable Tables (可調式表格): Drag column borders, use the `↔ Name` / `↔ Limit` sliders, or click `↔ Auto-Fit` to display long test names with zero truncation.
  • Executive PPTX & PDF Export: Generates professional 16:9 widescreen PowerPoint slides and executive print-ready PDF reports.

📐 Semiconductor Metrics Glossary

Match Rate: Percentage of test items whose limits, numbers, and units match exactly.
DSA Category (A/B/C/F): Severity categorization of parameter drift:
  • Cat A (Full Shift): Significant shift in Mean (>1.0) or Sigma Ratio (>2.0 or <0.5).
  • Cat B (Median Shift): Center-point drift in median (P50) or robust sigma.
  • Cat C: Minor marginal parameter drift.
  • Cat F: Normal / Flat (all properties match perfectly).
Binstate Switch Transitions:
  • pp: Pass in OLD ➔ Pass in NEW (Normal)
  • pf: Pass in OLD ➔ Fail in NEW (Critical yield fallout risk!)
  • fp: Fail in OLD ➔ Pass in NEW (Yield recovery)
  • ff: Fail in OLD ➔ Fail in NEW (Consistent failure)
Repeatability & Gauge R&R (CV%, Cp, Dist, Trend):
  • CV% (變異係數): $\frac{\sigma}{\mu} \times 100\%$，評估同一顆晶粒在多次重複測試中的相對離散程度。低於 1.0% 為極佳，超過 5.0% 代表測試機台或探針接觸存在重複性風險。
  • Cp (製程能力指標): $\frac{\text{USL} - \text{LSL}}{6\sigma}$，評估測試機台重複性散佈相對於規格公差帶寬的充裕度。$C_p \ge 4.0$ 為優秀能力水準，$C_p < 4.0$ 視為低能力/需關注 (Low Cp)。
  • Dist & Dist_Repeat: 形態分佈特徵（Normal, Skewed, Uniform, Bimodal），評估重複量測數據是否具備常態分佈特性。
  • Trend: 量測時序漂移行為（Stable, Positive Drift, Negative Drift, Level Shift），偵測測試機台是否有熱漂移（Thermal Drift）或接觸劣化。
TSR CPK Groupings: Outstanding (≥4.0), Capable (1.67–4.0), Marginal / Risk (0.5–1.67), Critical Defect (<0.5).

⚡ Top A/B/C Shift Severity Metric 計算準則 (無量綱標準化指標)

1. 為什麼需要標準化指標 (Scale-Invariant Z-Shift)？

在 ATE 測試中，不同參數的物理量綱差異極大（如漏電流為 $\mu\text{A}$、頻率為 $\text{MHz}$、電壓為 $\text{V}$ 或 $\text{mV}$）。若直接累加原始變異數或均值，會使單位較大的參數（如 $\text{mV}$）產生數千倍的數值膨脹，造成 Cat B（中位數偏移） 的長條圖尺寸失真。
因此系統全面採用 無量綱標準化效應指標 (Standardized Z-Shift)： Z_Shift = |ΔMean| / max(OLD_Sigma, NEW_Sigma)

2. 0 – 100 綜合風險嚴重度分級 (Normalized Severity Index)

系統將各參數的均值漂移、變異數倍率偏離度 $|\sigma_{\text{ratio}} - 1.0|$ 與 $\Delta\text{Cpk}$ 衰減懲罰歸一化至 0 – 100 分：
• Cat A (Full Shift, 70 – 100 分): 均值顯著位移、變異倍率劇增或 Cpk 大幅惡化。
• Cat B (Median Shift, 40 – 70 分): 中位數 (P50) 或中心點位移，屬於中度製程漂移。
• Cat C (Minor Drift, 15 – 40 分): 輕微邊際漂移。
• Cat F (Normal, 0 – 15 分): 規格與分佈吻合良好。

🔁 Repeatability & Per-ECID Gauge Analysis Guide (重複性測試與各顆晶粒分析指南)

1. 三種層級檢視視角 (Three View Modes)

• 視角 1 (ECID Die Summary): 依晶粒 (ECID) 聚合，呈現各 Die 的平均 CV%、最差 Cp、主導分佈與漂移趨勢長條圖。
• 視角 2 (Test Parameter Summary): 依測試項目聚合，跨所有晶粒統計 Mean CV%、Max CV%、Min Cp 與形態特徵。
• 視角 3 (Full Detailed Matrix): 展開每一顆 ECID 在各測試項目的完整量測明細，支援即時多條件過濾與欄位排序。

2. 快速過濾預設 (Quick Filter Presets)

• ⚡ High CV% (>5%)：一鍵篩選高變異接觸不良項目。
• ⚠️ Low Cp (<4.0)：一鍵篩選能力不足或需關注項目 (Cp < 4.0)。
• 📈 Drift / Shift Only：一鍵篩選存在時序漂移與位準跳躍之項目。

3. 即時數值追溯 (Click-to-Trace Formula)

點擊表格任一列或 Pareto 長條圖，可立即開啟右側追溯抽屜，完整檢視該 ECID/測試項目的 6-Sigma EV、$C_p$ / $\text{CPK}_n$、Ext_Drift 與原始 CSV 行資料。

🎛️ Interactive Table & Chart Controls (可調式表格與圖表操作指南)

1. 表格欄寬自由拉伸 (Drag-to-Resize)

在 TSR 測試報告 與 Bin Pareto 表格中，將滑鼠移至表頭欄位右側邊界（游標呈現 ↔），按住左鍵即可自由拉寬或縮小欄位；雙擊表頭把手 則可快速最適化該欄。

2. 寬度滑桿與 Auto-Fit 全展開

表格頂部提供 ↔ Name: [slider] 與 ↔ Limit: [slider] 即時滑桿，可一鍵拉寬整欄；點擊 ↔ Auto-Fit 可解除所有寬度限制，完整呈現無截斷。

3. 圖表全螢幕放大 (ESC 還原)

所有圖表卡片右上角設有 ⛶ 按鈕，亦支援 雙擊圖表 全螢幕放大檢視；按下鍵盤 ESC 鍵或點擊 ✕ 即可立即還原。

🚫 Test Ignore & Exclusion Filter (自動忽略與排除過濾機制)

1. NOT xxx NOT yyy 語法與應用場景

在 ATE 驗證與統計報告中，經常存在大量雜訊測試、Dummy/Empty 項目、設定程式（Setup Patterns）或特定輔助測試（如 PUX、OS_、Continuity、Leakage Setup）。
頂部導航與 DSA、TSR 分頁工具列提供 🚫 Test Ignore 功能，輸入規則後系統會自動排除指定測試，不需手動修改或重新上傳 CSV！
支援格式：
• not pux, not dummy 或 !pux, !setup
• pux, dummy, leakage（純關鍵字逗號分隔）
• pux*（字首萬用字元比對）

2. 連動重算範圍與即時追溯

• ⚡ DSA Parameter Shift: 自動排除 PUX/Dummy 後，重新即時計算 Cat A/B/C 分類總計、Top Shift 貢獻度排名、嚴重度指數與風險矩陣。
• 📈 TSR Test Summary: 自動排除特定測試後，重新計算總失效數、Loss %、Pareto 圖表與 CPK 能力分級。
• 🔍 即時追溯 (Trace Ignored): 點擊各分頁的 🔍 Trace Ignored 按鈕，可於右側追溯抽屜完整檢視所有被排除的測試項目與原始規格。

🔍 CSV Identification Mechanism (檔名識別 ＋ 內容特徵自動判定)

1. 檔名優先判定 (Filename Heuristics)

系統優先比對檔名關鍵字：
• 包含 repeatability、repeat_、rep_、_rep、retest、grr、gage ➔ 載入 Repeatability Analysis
• 包含 tsr、test_summary ➔ 載入 TSR Test Summary
• 包含 itemcompare ➔ 載入 Item Sanity
• 包含 dsacompare ➔ 載入 DSA Parameter Shift
• 包含 bincompare ➔ 載入 Bin & Yield Compare

2. 內容結構與欄位特徵兜底 (Content Signature Fallback)

若檔名為自訂名稱，系統自動掃描 CSV 表頭關鍵欄位特徵：
• 🔁 Repeatability: 偵測 Coordinate_ECID、Dist_Repeat、Ext_Drift、EV (6-Sigma)、Kurtosis (Excess) 或同時具備 ECID ＋ Mean ＋ Std ＋ CV (%)
• 📈 TSR Test Summary: 偵測 Loss_%、Fail_Count、Cpkn_Group、Distribution
• 🏷️ Bin Compare: 偵測 === Run Metadata ===、Binstate Switch Transitions
• ⚡ DSA Compare: 偵測 DSA_Group、Delta_Robust_Sigma、OLD_CPKn
• 🔍 Item Compare: 偵測 Status、Comparison、OLD_Test_Num
